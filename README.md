# 비품대장.xlsx 방탈출 미로 미니게임

엑셀 통합 문서처럼 보이는 정적(Static) 웹 게임입니다. **2차 업데이트**로 시트 4장(비품대장·보관실·비품실·전산실)을 통로로 오가는 방탈출 형식이 되었습니다. 인계 메모의 단서를 따라 마스터 열쇠를 찾아 잠긴 문(캐비닛·확인대장·보안문)을 열고, **마감 도장**과 **보안코드**를 모아 `비품대장 H12`에서 퇴근하면 끝납니다. 빌드 과정 없이 순수 HTML/CSS/JavaScript로 동작합니다.

## 플레이

https://bo05022002-max.github.io/bipum-ledger-maze/

## 시트와 탈출 흐름

| 시트 | 통로 | 내용 |
| --- | --- | --- |
| 비품대장 (`C6` 인계 메모) | `F4` → 보관실, `H4` → 전산실 | 시작점, 최종 마감 `H12` |
| 보관실 (`B8` 메모) | `A4` → 비품대장, `F4` → 비품실 | 서가 `A9~C9`에 마스터 열쇠, `E11` 확인대장(실사) |
| 비품실 | `A4` → 보관실, `H4` → 전산실 | 캐비닛 `D7`(열쇠) 안에 마감 도장 |
| 전산실 (`C6` 메모) | `A4` → 비품실, `G4` → 비품대장 | 보안문 `F8`(열쇠) 뒤 `F9` 서버 로그 = 보안코드 |

- 통로는 **양방향**이라 시트 사이를 자유롭게 오갈 수 있습니다. 통로 칸에서 `Enter`로 이동합니다.
- `💾 임시저장` 칸(`보관실 A8`, `비품실 C8`, `전산실 G7`)을 밟으면 그 시점이 저장됩니다. 검수에 걸리면 `Enter`로 그 자리에서 이어서 플레이합니다. `R`은 저장 지점까지 지우고 처음부터 다시 시작합니다.
- 검수(순찰)는 `검수 중`(전산실은 `보안 순찰`)으로 표시되고 0.8초마다 한 칸씩 움직입니다. `클립`을 얻으면 다음 칸이 점선으로 예고됩니다.
- `?day=YYYY-MM-DD`로 날짜를 지정하면 열쇠 위치·보너스 아이템·순찰 위치가 그날 배치로 고정됩니다(기본은 오늘).

## 조작

- `↑ ↓ ← →` : 셀 이동 (휴대폰은 화면 아래 방향 버튼)
- `Enter` : 메모 열기 / 통로 이동 / 캐비닛·확인대장 열기 / 실사 확인 / 마감 · 적발·마감 뒤에는 다시 시작(임시저장 지점 재개)
- `R` : 언제든 처음부터 다시 시작 (입력 중이거나 💬 의견 창이 열려 있으면 동작하지 않습니다)
- `F5` : 브라우저 새로고침 그대로 (게임이 가로채지 않습니다)
- `Esc` 또는 파일명 클릭 : 일반 보기 전환(숨김 — 검수와 시간은 계속 흐릅니다)

## 의견 보내기

화면 오른쪽 위 `💬 의견` 버튼을 누르면 개선 의견·버그 제보 창이 열립니다. 제목, 내용, 회신 받을 이메일(선택)을 적고 `보내기`를 누르면 정적 페이지(서버·계정 없음)에서도 [FormSubmit](https://formsubmit.co) 무료 폼 전달 서비스를 거쳐 `woong6.park@gmail.com`으로 전달됩니다.

- 전송 방식: `https://formsubmit.co/ajax/<토큰>`으로 `fetch` POST(JSON)하고, 돌아온 `{"success":"true"}` 응답을 확인했을 때만 창에 `보냈습니다`를 표시합니다. 20초 안에 확인되지 않거나 실패하면 같은 창의 `메일 앱으로 보내기`(mailto)를 안내합니다.
- 받는 메일 주소는 페이지 소스에 그대로 두지 않습니다. FormSubmit이 발급한 대체 토큰을 전송 주소로 쓰고, 실제 주소는 `app.js`에서 조합해 mailto에만 씁니다.
- 스팸 봇 차단용 숨김 필드(`#fbHoney`)에 값이 있으면 전송하지 않고 조용히 성공 화면만 보여 줍니다. `_captcha=false`, `_subject`, `_template=table`, `페이지`, `환경`(날짜·화면 크기·보기 상태·기기)을 함께 보냅니다.
- `index.html`이 최대 10분 캐시되므로, 배포 후 화면이 그대로면 `?v=` 값을 올려 다시 배포하면 즉시 반영됩니다.

## 검사

```bash
node --test "tests/*.test.mjs"     # 규칙·지도 검사 15개
node tests/sim-deep.mjs            # 90일치 자동 플레이(순찰 회피·임시저장 재개 포함)
```

- 지도 검사: 벽/특수 칸 좌표, 통로 4쌍의 양방향 일치, 순찰로에 특수 칸이 깔리지 않음, 모든 바닥 칸 연결, 잠긴 문이 열쇠 없이 막히는지.
- 경로 검사: 60일치 배치마다 상태 공간 탐색으로 "인계 메모 → 마스터 열쇠 → 잠긴 문 → 도장·코드 → 실사 → H12" 경로가 있는지 확인하고, 실제 엔진으로 그 경로를 실행해 마감까지 가는지 확인합니다.
- 자동 플레이: 90일치를 순찰을 피해 실제로 플레이해 모두 완주하는지 확인합니다.

## 기타

- 저장은 브라우저 `localStorage`/`sessionStorage`만 사용하며 게임 기록은 서버로 보내지 않습니다. 의견 폼으로 보낸 내용만 FormSubmit을 거쳐 메일로 전달됩니다.
- 결과 복사 시 공유 URL은 접속한 페이지의 주소(`location.origin + location.pathname`)를 그대로 사용합니다.
